## m1.3：合并拆床率、隐身偏好与撤退调整 - 2026-10-22

### Changed

- 正式默认普通拆床率在0–30分钟按自然指数从8%降至3%，隐身拆床率线性从60%降至40%；在拆床结算时取值，新增可配置终点。
- 无床玩家的隐身/普通进攻基础权重比乘2；相遇退出或进攻失败后的条件死亡率乘0.5，默认30%死亡、70%撤退。资源限制、追击击杀概率和观察终点保留，不合入强制备药收集。
- 保持全部隐身越界统计，配置与输出记录当前模型版本；增加曲线、决策与实际战斗路径回归测试。
- 与既有真实记录进行描述性对比，分析脚本、生成结果与私有数据仍由Git忽略；没有执行参数拟合。

## M1 统计口径调整：全部攻击事件 - 2026-10-21

### Changed

- 首次隐身攻击后继续模拟，记录观察期内每次有效越界；模型版本更新为 `m1.2`。
- 时间曲线使用全部攻击次数 /（全部对局数 × 分箱宽度），面积改为每局平均攻击次数。
- 分开输出每箱至少遭遇一次攻击的概率，避免把重复事件计数误标为概率。
- 新增 `attacks.csv`，保存逐局攻击序号、时间与来源；逐局表增加总攻击数和首末时间，输出 schema 更新为 2。
- 稳定性改为全次数的平均累计攻击曲线，并使用按整局重采样的近似 bootstrap 误差带；首事件历史验收单独标注。
- 显式声明 NumPy 依赖，用于整局重采样统计。

### Validation

- 36 项测试通过，210,000 局通过每事件状态与事件计数检查。
- 同种子 10,000 局的逐次、逐局和分箱 CSV 完全复现；共记录 2,649 次第二次及以后攻击。
- 最后两组平均累计次数最大差异 0.01128125，低于整局 bootstrap 近似误差带阈值 0.01149375。
