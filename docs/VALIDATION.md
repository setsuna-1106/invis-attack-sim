# 验证说明

## 行为与输出检查

运行 `python -m unittest discover -s tests -v` 检查配置校验、生成时钟与库存、收集等待和拾取公平性、搭桥与返程、相遇取消、目标变化、死亡后动作取消及重生资格。测试还覆盖隐身越界与拆床同刻发生、隐身恰好到期及观察上限端点。

使用同一配置和种子分别运行两次，逐局 CSV 与分箱 CSV 应完全一致。运行摘要中的耗时可以不同。`--audit` 在每个事件处理后检查状态约束；所有输出均检查密度积分与未遭遇概率之和。

## 样本稳定性

`stability` 命令使用三组不同种子及递增的样本数，并比较未经分箱的经验累计分布。未发生事件的对局保留为无穷远处的概率质量，避免按有事件样本重新归一化。

最后两组样本量为 n、m 时，采用 Dvoretzky–Kiefer–Wolfowitz 界与联合误差控制：

```text
epsilon(k) = sqrt(log(80) / (2k))
通过条件：sup_t |F_n(t) - F_m(t)| <= epsilon(n) + epsilon(m)
```

两组独立样本的误差界同时成立概率至少为 95%。未通过时保留结果并返回非零退出码。通过说明该次累计分布差异落在抽样误差界内，不代表模型真实性已获验证，也不保证每个 5 秒箱的密度都稳定。
